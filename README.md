# **Hello, and welcome to Oka's abong's Minecraft Bedrock Add-on library!** 
## This is specifically for you to download the add ons I create that you want, and enjoy it.

So, what packs or add ons do I create? About games. About movies. about books (I rarely do that) and some fun Easter eggs! (though those Easter Eggs are obvious...) Just download a pack and open it with Minecraft Bedrock. Enjoy!

By the way please do not download the repository via git cloning. Download it via the Code drop-down and Download. Thanks! :)

Also, unlike Marketplace packs, instructions for each pack is not in-game. See the Hello.md in each folder for instructions.

Note that Vibrant Visuals add-ons will not be in this library. Find them in the upcoming Minecraft Creator Platform!
